= A1: BGN/PCGN coverage diff (held system documents vs corpus)

Official catalog source: the bgn-pcgn/ system documents held in
interscript-references (55 PDFs -- each is one system's authoritative
document). geonames.nga.mil (the consolidated schedule) is unreachable
from here; the held set is the verifiable catalog.

Corpus encodes ~37 systems across 54 bgnpcgn-* maps (several systems
carry script/year variants: kor x3, div x2, ell x2, kat x2, mkd x2,
tuk x2, ukr x2, uzb x2, prs x2, srp x2, bul x2, fao x2, isl x2).
