== Method (the law: transcribe whole documents)

1. Capture each authority's official system list from the primary
   source (raw capture committed here, never paraphrased from memory).
2. Transcribe table names -> ISO 24229 codes (authority-language-
   SrcScript-DstScript-year) with the name->code evidence inline.
3. Diff against the corpus; every gap becomes either an encoding PR
   (whole-document transcription) or an out-of-scope citation with the
   authority reference.

Acceptance: zero unexplained gaps.
