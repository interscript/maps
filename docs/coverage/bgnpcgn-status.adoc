== BLOCKED: no corpus, no model, no data source (5 systems)
- Burmese (mya) — abugida, Myanmar script U+1000-U+109F
- Dzongkha (dz) — abugida, Tibetan script U+0F00-U+0FFF
- Inuktitut (iu) — syllabics U+1400-U+167F
- Lao (lao) — abugida, Lao script U+0E80-U+0EFF
- Shan (shn) — abugida, Myanmar script

These are BLOCKED because:
1. The deterministic ISC table alone is insufficient for abugidas
   (inherent vowels, conjuncts, tone marks require linguistic knowledge)
2. No training corpus exists in our data supply
3. No neural model exists
4. Without a model, the deterministic table alone produces inadequate
   results

Policy: it is better to withhold than to give bad quality.
The tables will be encoded ONLY when a model or corpus unblocks them.
